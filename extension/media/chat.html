How Maestro works

You talk to one chat. A local conductor on 127.0.0.1:8788 routes each message to a CLI you already logged into. Maestro does not read API keys.

  1. Classify — chat, write, code, debug, review, or plan, plus a difficulty score.
  2. Plan — Auto picks one CLI. Quality / Value / Speed / Cheap fan out like OpenRouter Fusion, then a judge writes one answer.
  3. Run — launches claude, grok, codex (OpenAI), kimi, or zcode (Zai/GLM).
  4. Verify / escalate — hard tasks get a second CLI. REVISE can promote to a stronger one.

Quality = Opus 5 + GPT-5.6 Sol + Grok 4.6, Opus 5 fuses. Value = Sonnet 5 + GPT-5.6 Terra. Speed = Grok 4.6 + Kimi K2.7 Highspeed + GLM-5 Turbo. Cheap = Kimi K3 + GLM-5.3. Change any of these in Configure.
