How Maestro works

One chat. A local conductor on 127.0.0.1:8788 routes each message to a CLI you already logged into.

  1. Classify — chat, write, code, debug, review, or plan.
  2. Plan — Auto picks one CLI. Quality / Value / Speed / Cheap fan out, then a judge writes one answer.
  3. Run — launches a local CLI, or calls OpenRouter if you picked one of those models.
  4. Verify — hard tasks get a second CLI. REVISE can escalate.
