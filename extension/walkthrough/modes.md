# Ask vs Agent, Auto vs Fast vs Ultra

**Ask** is read-only. Start here.

**Agent** lets Claude / Grok / OpenAI / Kimi / Zai edit the current workspace.

**Auto (Maestro)** classifies the prompt, picks a CLI, and verifies hard work.

**Fast** uses the cheapest capable CLI only.

**Ultra** runs two drafts and synthesizes one answer.
