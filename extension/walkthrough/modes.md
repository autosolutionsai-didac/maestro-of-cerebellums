# Work modes and routing

**Ask** — one CLI, read-only answer. Start here.

**Plan** — one CLI writes numbered steps and stops. No edits.

**Architect** — two CLIs design; a judge unifies. No edits.

**Agent** — CLIs may edit this workspace. File edits are accepted; they may still ask before shell or network.

**Yolo** — same as Agent, but every permission is pre-approved. Nothing prompts.

**Review** — review-strong CLI plus a verifier. Findings only.

**Auto (Maestro)** classifies the prompt and picks a CLI.

**Fast** uses the cheapest capable CLI only.

**Quality / Value / Speed / Cheap** run Fusion panels. Only Agent lets those workers write files.
